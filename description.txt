# Challenge: Deep Work Session Tracker
## Objective:
Build a system to plan, start, pause, resume, and complete focused work
sessions.
Track interruptions and provide summaries for productivity reflection.
Includes FastAPI + SQLite backend, ReactJS frontend, Python SDK,
automation scripts.
Your solution should be fully functional, adhere to OpenAPI standards,
and demonstrate best practices in backend, frontend, database, and SDK
development.
---
## Tasks & Requirements
### 1. Backend Development (FastAPI & SQLite)
Implement a FastAPI service with the following endpoints:
- **POST /sessions/** → Schedule a new work session (title, duration,
goal).
- **PATCH /sessions/{session_id}/start** → Start the session.
- **PATCH /sessions/{session_id}/pause** → Pause the session (log
interruption reason).
- **PATCH /sessions/{session_id}/resume** → Resume a paused session.
- **PATCH /sessions/{session_id}/complete** → Mark session completed
(store completion time).
- **GET /sessions/history** → Summary of past sessions (durations,
pauses, completion ratio).
Use SQLite as the database.
Ensure the API follows OpenAPI standards (Swagger UI should be
accessible).
Implement error handling (appropriate 4xx/5xx).
Use dependency injection for database operations.
Write unit tests for the backend.
#### Trick Logic in Backend (Hidden Complexity)
- A session can only be **paused** if it's currently **active**.
- If paused more than **3 times**, mark the session as **interrupted**.
- A session must be completed within **10%** of its original duration,
else **overdue**.
- If never resumed after a pause → **abandoned**.
**Your implementation should correctly enforce the rules above.**
** Examples:**
- 50-min session paused 2× → **completed**
- Paused 4× → **interrupted**
- Not resumed after pause → **abandoned**
- Completed 60 mins after 50 → **overdue**

### 2. Database (SQLite)
Create the following database tables:
```
CREATE TABLE sessions (
id INTEGER PRIMARY KEY AUTOINCREMENT,
title TEXT NOT NULL,
goal TEXT,
scheduled_duration INTEGER NOT NULL,
start_time TIMESTAMP,
end_time TIMESTAMP,
status TEXT CHECK (status IN
('scheduled','active','paused','completed','interrupted','abandoned','ove
rdue')) DEFAULT 'scheduled',
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
```
CREATE TABLE interruptions (
id INTEGER PRIMARY KEY AUTOINCREMENT,
session_id INTEGER NOT NULL,
reason TEXT NOT NULL,
pause_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
FOREIGN KEY (session_id) REFERENCES sessions(id) ON DELETE CASCADE
);
```
Use Alembic for database migrations.
Provide a sample SQL file (`seed_data.sql`) to populate initial test
data.

### 3. Frontend Client (ReactJS)
Develop a ReactJS-based frontend.
Use Axios for making API calls.
The frontend should allow users to:
- Schedule a session (title, goal, duration)
- Start/Pause/Resume/Complete a session
- Enter reason when pausing
- View history including status and stats
- (Bonus) Live countdown timer while active
Ensure the frontend interacts only via API calls (no direct database
access).
Style is not a priority, but functionality must work correctly.
** Bonus:** Real-time updates where meaningful.

### 4. Platform SDK (Generated via OpenAPI Generator CLI)
Instead of manually writing an SDK, generate a Python SDK using the
OpenAPI Generator CLI. This SDK should allow interaction with the API.
**Instructions to Generate SDK**
```bash
npm install -g @openapitools/openapi-generator-cli
openapi-generator-cli generate -i http://localhost:8000/openapi.json -g
python -o deepwork_sdk
```
**Expected SDK Usage (After Generation & Testing):**

### 5. Development Setup Script (`setupdev.bat`)
Create a Windows batch script to set up the environment:
```bat
@echo off
echo Setting up backend...
python -m venv env
call env\Scripts\activate
pip install -r requirements.txt
alembic upgrade head
echo Setting up frontend...
cd frontend
npm install
cd ..
echo Setup complete.
```
---
### 6. Execution Script (`runapplication.bat`)
Create a Windows batch script to start the full application.
```bat
@echo off
echo Starting backend...
call env\Scripts\activate
python main.py
echo Starting frontend...
cd frontend
npm start
```
