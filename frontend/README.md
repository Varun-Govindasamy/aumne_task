# Deep Work Session Tracker Frontend

The React client uses Axios to communicate with the FastAPI service at `http://127.0.0.1:8000`.

From this directory, install dependencies and start the development server:

```sh
npm install
npm start
```

The Vite server runs at `http://localhost:5173`. The backend must be running for session data and actions to load.

Create a production build with `npm run build`.
